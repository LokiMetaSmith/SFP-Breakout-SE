## Archived: 2026-10-31

* Repository context:
  * Name: SFP-Breakout-Board
  * Description: A modified version of Anders Wallins SFP Breakout Board. It acts as an SFP fibre-optical transceiver breakout board supporting up to 1 Gbit/s.
  * Modifications from original: Features single-ended TX and RX outputs/inputs with SMA connectors (using LVDS/LVPECL converters) and a cheaper LDO.
  * Retained features: SFP/SFP+ connector and cage, +3V3 power, status LEDs (TX_FAULT, LOS, MOD_ABS), and rate-select jumpers.
  * License: CERN OHL v. 1.2
  * Design Files: KiCad PCB, Pro, Sch files.
* Active session memories: None recorded prior to this archiving request.
